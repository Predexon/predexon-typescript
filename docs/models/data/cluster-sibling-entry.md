# ClusterSiblingEntry

One sibling wallet related to the seed via on-chain transfer graph signals.

## Example Usage

```typescript
import { ClusterSiblingEntry } from "@predexon/sdk/models/data";

let value: ClusterSiblingEntry = {
  address: "68658 Dave Branch",
  confidence: 739335,
  minHops: 608378,
  evidence: {},
};
```
