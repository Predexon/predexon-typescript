# RouterOrder

Partner-facing router-order envelope. Same shape across POST /router/orders (market + limit), GET /router/orders (list rows), and GET /router/orders/{routerOrderId}. Always returned at HTTP 201 from POST regardless of fill outcome — read `status` for the rollup (`failed` when no leg filled). GET detail adds `decisionSnapshot` on limit orders.

## Example Usage

```typescript
import { RouterOrder } from "@predexon/sdk/models/trading";

let value: RouterOrder = {};
```
